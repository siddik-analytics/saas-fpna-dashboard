# SaaS FP&A Dashboard

A portfolio project that simulates a SaaS company finance environment using SQL and Power BI.

## Project Objective

Build a finance dashboard for a SaaS business to track:

- ARR
- Revenue
- Customers
- Churn
- CAC
- LTV
- Gross Margin
- Burn Rate
- Runway

## Tools Used

- SQL
- Power BI
- Excel / CSV
- GitHub

## Project Structure

- `data/` → raw and cleaned datasets
- `sql/` → schema, transformations, KPI calculations
- `powerbi/` → DAX measures and dashboard notes
- `images/` → screenshots of dashboard
- `docs/` → project documentation

## KPI Metrics

- ARR Growth %
- Gross Margin %
- Burn Rate
- Runway (Months)
- Churn %
- CAC
- LTV
- LTV/CAC
